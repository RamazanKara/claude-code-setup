# Personal rules

Machine- and person-specific rules. The installer copies this to `~/.claude/personal.md` once and never overwrites it; `CLAUDE.md` imports it.

## Environment
- OS and shell, e.g. "Windows 11, elevated" or "macOS, zsh".
- Where projects live, e.g. "Projects under `\\wsl.localhost\ubuntu\home\me\git\`: run their tooling inside WSL."
